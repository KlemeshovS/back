## Пари (1v1)

Два друга запускают **пари** — соревнование между собой с обнулённым счётом.
У каждого пари свой независимый рейтинг, глобальный рейтинг при этом живёт сам по себе.

Механика:
- Пари можно создавать сколько угодно — с разными людьми одновременно
- Один создаёт пари и выбирает с кем соревноваться (из друзей)
- Второй должен подтвердить пари
- С момента подтверждения у обоих счёт пари = 0, начинают считать заново
- Глобальный счёт не затрагивается
- Отдельная вкладка «пари» в приложении — список активных пари + кнопка создать

Открытые вопросы:
- Есть ли условие победы (по времени, по очкам) или пари бессрочное?
- Можно ли отменить/завершить пари досрочно?

## Группы / Лобби

Аналог пари, но для 3+ человек. Собрались, запустили группу — у всех обнулённый счёт внутри группы, глобальный живёт отдельно.

**Таблицы:**
- `groups` — id, name, owner_id, invite_code, created_at
- `group_members` — group_id, user_id, role (owner/member), joined_at

**API:**
```
POST   /groups
GET    /groups
GET    /groups/{id}
PATCH  /groups/{id}
DELETE /groups/{id}
POST   /groups/join                  — по invite_code
POST   /groups/{id}/members          — добавить по username (owner)
DELETE /groups/{id}/members/{user_id}
GET    /groups/{id}/leaderboard
```
